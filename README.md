# Welcome to the CrawlerGame Repository

This is the repository for the video game CrawlerGame, CrawlerGame was made to learn C++
and other things.

## Info

Menu Clusters : MainMenu.h/cpp & MenuGame.h/cpp  
Player Clusters : CrawlerPlayer.h  
Item and Inventory Clusters : Inventory.h/cpp & Item.h/cpp

### How to set up sound

To set up sound in the game you must build the program once and then unzip Sounds&Mus.zip in the same folder as the exicuteable.

### How to share the game

To share the game ; compile the project in relese, unzip "Needed dll's.zip" and place in in the same folder as the relese exacuteable.
Then use Inno instaler to set up an instaler, and KABLAO! share as much as you want.
